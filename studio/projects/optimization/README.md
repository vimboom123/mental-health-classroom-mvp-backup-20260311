# optimization/

这里放网站项目第一版**不阻塞开发**的优化方向材料。

原则：
- 这些文档有价值
- 但不应压过 MVP 主线
- 第一版先把基础功能做出来，再逐步吸收这里的内容

## 子目录说明

### `risk-safety/`
更细的助教安全、风险表达和边界优化材料。
适合在：
- 助教安全增强
- 更细风险策略
- 更稳妥的中文表达
阶段使用。

### `interaction-ui/`
更细的交互、页面状态、风险态 UI、组件状态和事件流材料。
适合在：
- 前端增强
- 更细交互设计
- 状态驱动实现优化
阶段使用。

### `testing-eval/`
更细的测试、Prompt 验收、样本库与回归测试材料。
适合在：
- Prompt 调优
- 模型版本比较
- 回归测试
阶段使用。
