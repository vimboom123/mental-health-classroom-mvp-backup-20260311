# 网站页面流程、内容映射与助教角色设定（V1）

## 一、网站页面流程（V1）

### 1. 主流程
首页 → 模块总览页 → 单模块详情页 → 情景模拟页 / 智能助教页 / 资源中心页

### 2. 首页流转
用户进入首页后，有四条主要路径：
1. 进入课程模块
2. 直接进入智能助教
3. 进入热门练习/情景模拟
4. 进入风险帮助页

### 3. 模块学习流转
模块总览页 → 选择模块 → 单模块详情页 → 进入练习或与助教对话 → 返回模块页继续学习

### 4. 智能助教流转
首页 / 模块页 / 情景模拟页 均可进入智能助教页。
进入后可：
- 直接提问
- 点击常见问题
- 跳转到推荐练习
- 跳转到资源中心
- 在需要时进入风险帮助页

### 5. 情景模拟流转
首页推荐入口 / 模块详情页 → 情景模拟页 → 开始练习 → 获取反馈 → 进入反思问题 → 回到模块页或助教页

### 6. 风险帮助流转
任何页面遇到敏感风险场景时，都应能快速跳转到风险帮助页。
风险帮助页应作为全站兜底页面存在。

## 三、助教角色设定草案（V1）

### 1. 角色定位
这是一个陪伴式、引导式、课程内嵌型智能助教。
它不是客服，不是娱乐角色，也不是泛聊天伙伴。

### 2. 角色功能身份
它在网站中的身份更接近：
- 课程助教
- 练习引导员
- 资源导航员
- 情境互动陪练助手

### 3. 角色气质
- 温和但不软弱
- 亲近但不过分卖萌
- 可靠、稳定
- 回答直接、清晰
- 更像一个靠谱的青年学习陪伴者

### 4. 角色语言风格
- 用自然中文表达
- 不说教
- 不像教务通知
- 不像客服模板
- 不装专业咨询师
- 优先用清楚、可执行的表达方式

### 5. 角色在不同场景下的状态
- 首页：欢迎与引导
- 模块页：提示学习重点与进入方式
- 助教页：完整互动主状态
- 情景模拟页：陪练与反馈状态
- 风险场景：更克制、更稳、减少过度活泼动作

### 6. 角色视觉与动态原则
- 第一版采用 Nano Banana 生成角色素材
- 动态效果由前端实现
- 动作不追求炫技，优先稳定、自然、轻量
- 动效服务于陪伴与引导，不抢内容主线
