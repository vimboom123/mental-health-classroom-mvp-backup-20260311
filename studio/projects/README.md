# 数智赋能示范课堂 MVP

零依赖 Node 站点，用来先跑通网站 MVP 主链路：

- 首页
- 模块总览页
- 三个模块详情页
- 智能助教页
- 风险帮助页
- 三个情景练习页
- `/api/tutor` 结构化接口
- `/api/tutor/meta` API 准备状态接口

## 运行

```bash
npm start
```

开发模式：

```bash
npm run dev
```

## 环境变量

复制 `.env.example` 为 `.env` 后填值：

- `PORT`: 本地端口，默认 `3000`
- `DASHSCOPE_API_KEY`: 千问 DashScope OpenAI 兼容接口 Key
- `DASHSCOPE_MODEL`: 默认 `qwen-plus`
- `DASHSCOPE_BASE_URL`: 默认 `https://dashscope.aliyuncs.com/compatible-mode/v1`

没有配置 Key 时，助教 API 会自动回退到本地规则回复，但仍会返回：

```json
{
  "reply": "...",
  "riskLevel": "low",
  "recommendedActions": [],
  "uiState": {}
}
```

`GET /api/tutor/meta` 会返回当前模型配置状态、接口入口和结构化字段清单，方便前端联调和验收。
