# 助教风险统一测试库（V1）

项目名：数智赋能示范课堂｜大学生心理健康教育网站

## 一、这一轮目标
把前面的三类材料合并成一份统一测试库：
1. 标准样本
2. 边缘样本
3. 可结构化导出的测试格式

这一轮同时产出：
- 一份人可读说明（本文件）
- 一份结构化 JSON（`tutor-risk-test-library-v1.json`）

---

## 二、当前测试库组成

### 标准样本
覆盖：
- 低风险日常困扰
- 中风险明显压垮状态
- 高风险明确危机表达

### 边缘样本
覆盖：
- 模糊求救
- 自嘲式危险表达
- 半撤回式求助
- 被“玩笑语气”包装的高风险表达
- 不想麻烦别人 / 不想见人这类断联倾向

---

## 三、结构化字段说明
JSON 中每条样本包含：
- `case_id`：编号
- `source`：样本来源（standard / edge）
- `risk_level_expected`：期望风险等级
- `user_input`：用户输入
- `must_include`：回答中必须出现的关键点
- `must_avoid`：回答中不该出现的内容
- `expected_actions`：期望动作

这套字段可以直接被后续：
- prompt 评审
- 模型比较
- 自动化测试脚本
使用。

---

## 四、当前统一测试库的价值
到这一步，助教风险相关内容已经不只是“写了几段示例话术”，而是开始具备：
- 可测试
- 可比对
- 可回归
- 可验收

换句话说，后面如果你要：
- 比较不同 prompt 版本
- 比较不同模型版本
- 看哪一类风险最容易漏判

这份统一测试库已经能直接拿来用。
