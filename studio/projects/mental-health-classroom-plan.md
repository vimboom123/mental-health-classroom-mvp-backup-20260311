# 数智赋能示范课堂-大学生心理健康教育｜工作室项目底座

## 1. 项目目标
基于已通过的《数智赋能示范课堂建设申报书》，把“大学生心理健康教育”课程从申报文本落成可执行项目，形成可展示、可实施、可验收的数智赋能示范课堂建设方案与首批交付物。

## 2. 项目定位
- 项目类型：示范课堂建设 / 教学产品化项目
- 当前阶段：项目底座搭建
- 项目原则：先做可运行最小版本（MVP），再扩展完整平台能力

## 3. 建议第一阶段交付标准（MVP）
### 必须交付
1. 课程整体实施蓝图（按七大模块拆解）
2. 教学设计与任务分解表
3. 内容资源清单（课件/脚本/知识库/练习表）
4. 智能助教知识库框架
5. 2-3 个高价值 AI 情景模拟样例
6. 伦理与风险边界草案
7. 阶段推进与验收指标表

### 暂不强求一步到位
1. 完整数字人高仿真系统
2. 完整个性化推荐引擎
3. 真正上线的高危预警闭环

## 4. 角色分工
- 主智能体：PM / 验收 / 统稿 / 汇报
- Codex：结构拆解、实施方案骨架、任务表
- Gemini：表达层、汇报可读性、展示结构
- Claude Code：审稿、逻辑复核、风险检查
- Qwen：中文润色、本土化表达、中文材料适配
- Oracle：全局复盘、第二视角、收口判断

## 5. 当前风险
1. 申报书承诺范围大，真实资源和平台能力未确认
2. 心理健康课程涉及伦理与预警，高风险能力不能直接空落地
3. 若一开始追求“完整平台”，项目容易失焦和拖期

## 6. 下一步
1. 先输出项目正式执行版路线图
2. 再拆解为：教学模块 / 功能模块 / 资源模块 / 风险模块
3. 然后形成第一版实施方案和任务清单
