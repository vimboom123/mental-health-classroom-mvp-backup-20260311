# 网站 MVP 开发任务拆分表（V1）

项目名：数智赋能示范课堂｜大学生心理健康教育网站

## 一、这一轮目标
把当前主线文档进一步收口成一版真正可执行的开发拆分表。

目标不是再写方案，而是明确：
- 第一版到底要做哪些开发任务
- 这些任务怎么分组
- 哪些先做，哪些后做
- 每项任务的完成标准是什么

---

## 二、开发拆分原则

### 1. 先跑通闭环，不先追求复杂
第一版优先：
- 页面能进
- 内容能看
- 助教能问
- 千问能接
- 风险能分流
- 练习能进入

### 2. 任务按四类拆
- 前端页面
- 后端 / API
- 内容填充
- 风险与验收

### 3. 每类任务都尽量可独立验收
做完一项，能看得见结果，而不是全靠想象。

---

## 三、P0：必须完成的任务

# A. 前端页面任务

### FE-01 首页骨架
**目标**
完成首页第一版页面。

**至少包括**
- Hero 区
- 三大模块入口
- 助教入口
- 热门练习入口
- 风险帮助入口

**完成标准**
- 页面能打开
- 关键入口可点击
- 不要求复杂视觉，只要结构清楚

---

### FE-02 模块总览页
**目标**
完成模块总览页。

**至少包括**
- 三大首批模块卡片
- 每个模块一句说明
- 进入模块按钮

**完成标准**
- 可从首页进入
- 可进入对应模块详情页

---

### FE-03 三个模块详情页
**目标**
完成三大模块的详情页模板与内容填充。

**模块**
- 人际交往
- 学习心理
- 情绪调节

**至少包括**
- 模块简介
- 典型问题
- 核心认识
- 方法
- 练习入口
- 助教引导提问示例

**完成标准**
- 三页都能独立访问
- 每页都有可读内容和跳转入口

---

### FE-04 助教页基础版
**目标**
完成助教页第一版。

**至少包括**
- 页面标题与说明
- 助教角色区
- 聊天区
- 输入框
- 快捷问题
- 推荐动作区

**完成标准**
- 可以输入并收到回复
- 有最基本的 UI 状态切换

---

### FE-05 风险帮助页
**目标**
完成风险帮助页第一版。

**至少包括**
- 现在先做什么
- 可以联系谁
- 校内支持资源占位
- 校外 / 全国支持资源占位
- 紧急情况提醒

**完成标准**
- 可从首页和助教页进入
- 内容结构清楚

---

### FE-06 情景模拟页 × 1~2
**目标**
完成 1~2 个练习页。

**建议首批**
- 室友作息沟通
- 考试前从混乱状态重新启动

**完成标准**
- 模块页能跳转进入
- 页面能展示场景说明与练习目标

---

# B. 后端 / API 任务

### BE-01 千问 API 接入
**目标**
打通助教对话请求链路。

**至少包括**
- 前端发送输入
- 后端请求千问
- 返回文本回复

**完成标准**
- 助教页能正常得到模型回复

---

### BE-02 助教返回结构统一
**目标**
让后端返回不只是文本，还包括前端可用的结构化字段。

**建议返回格式**
```json
{
  "reply": "...",
  "riskLevel": "low",
  "recommendedActions": []
}
```

**完成标准**
- 前端能根据 `riskLevel` 和 `recommendedActions` 切状态

---

### BE-03 风险等级输出（简版）
**目标**
支持 low / medium / high 三档输出。

**完成标准**
- 至少能驱动前端三态切换
- 不要求第一版非常复杂，但要稳定

---

# C. 内容填充任务

### CT-01 三个模块内容填入页面
**目标**
把已有示例内容真正填入模块页。

**完成标准**
- 三个模块都不再是空壳页

---

### CT-02 首页文案填入
**目标**
把首页用户可见文案填入首页骨架。

**完成标准**
- 首页第一屏、模块区、助教引导区都有真实文案

---

### CT-03 助教页说明文案填入
**目标**
把助教页标题、边界说明、快捷问题填入。

**完成标准**
- 助教页不是空聊天框
- 有基础引导语

---

### CT-04 风险帮助页内容填入
**目标**
把风险帮助页结构与基础文案填进去。

**完成标准**
- 页面能读懂
- 不需要等所有学校资源都收全才开始开发

---

# D. 风险与验收任务

### QA-01 助教低 / 中 / 高风险三态联动
**目标**
前端根据 `riskLevel` 正确切换状态。

**完成标准**
- low：正常学习态
- medium：风险帮助前置，模块降级
- high：安全优先，普通模块隐藏

---

### QA-02 风险帮助页联动验证
**目标**
中高风险场景下，风险帮助页入口要正确出现。

**完成标准**
- medium：明显提示
- high：强提示 / 主位显示

---

### QA-03 最小路径验收
**目标**
验证第一版主链是否跑通。

**验收路径**
首页 → 模块页 → 助教页 → 风险帮助页 / 练习页

**完成标准**
- 整条路径可走通
- 没有关键死链

---

## 四、推荐开发顺序

### 第 1 轮
- FE-01 首页骨架
- FE-02 模块总览页
- FE-03 三个模块详情页
- CT-01 / CT-02 内容填入

### 第 2 轮
- FE-04 助教页基础版
- BE-01 千问 API 接入
- BE-02 助教返回结构统一
- CT-03 助教页文案填入

### 第 3 轮
- FE-05 风险帮助页
- BE-03 风险等级输出
- QA-01 / QA-02 风险联动验证
- CT-04 风险帮助页内容填入

### 第 4 轮
- FE-06 情景模拟页 × 1~2
- QA-03 最小路径验收

---

## 五、第一版可以暂缓的任务

这些不阻塞 MVP：
- 更复杂的动画角色
- 更完整的测试库接自动化
- 更细的风险 UI 优化
- 更复杂的 prompt 压测
- 更多模块扩展
- 教师端 / 后台
