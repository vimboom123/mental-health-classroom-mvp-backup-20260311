# 网站产品总方案（V1）

项目名：数智赋能示范课堂｜大学生心理健康教育网站

## 1. 项目定义
这是一个面向大学生心理健康教育场景的网站产品，而不是单纯的课程材料整理页。
网站核心不是展示文件，而是把课程内容、互动练习、资源支持与智能助教整合到一个统一入口中。

## 2. 产品目标
搭建一个可实际使用的网站，服务大学生心理健康教育课程的学习、练习与陪伴支持。
网站内置智能助教，直接调用千问 API，并配备可动的动画形象，增强互动感与陪伴感。

## 3. 核心用户
### 3.1 学生
- 学习课程内容
- 获取情境化帮助
- 进行互动练习
- 获得资源支持

### 3.2 教师
- 承载课程内容
- 提供课后支持入口
- 组织学生完成模块练习
- 后续可扩展到查看使用反馈

## 4. 产品核心组成
### 4.1 网站内容层
- 课程模块内容
- 学习与练习资源
- 情景模拟内容
- 风险帮助信息

### 4.2 网站功能层
- 首页入口
- 模块学习页
- 智能助教交互入口
- 情景模拟入口
- 资源中心
- 风险帮助入口

### 4.3 智能助教层
- 网站内置
- 直接调用千问 API
- 承担课程答疑、练习引导、资源推荐、互动陪伴等功能
- 具备动画形象与状态动作，不是静态角色

## 5. 网站信息架构（V1）
### 5.1 首页
作用：统一入口，解释网站是什么、能做什么、从哪里开始。
包含：
- 项目简介
- 快速进入课程模块
- 智能助教入口
- 热门练习入口
- 风险帮助入口

### 5.2 课程模块页
作用：承载课程主要内容。
建议首批模块：
- 人际交往
- 学习心理
- 情绪管控
后续扩展：
- 心理健康与心理辅导
- 自我意识
- 恋爱与性
- 生命教育

### 5.3 智能助教页
作用：作为核心互动区。
包含：
- 助教角色形象
- 对话窗口
- 常见问题快捷入口
- 推荐练习入口
- 风险提示与转介入口

### 5.4 情景模拟页
作用：提供结构化互动练习。
首批对应模块：
- 人际交往场景
- 学习心理场景
- 情绪管控场景

### 5.5 资源中心
作用：提供练习表、方法卡、工具包、帮助入口。
包含：
- 情绪记录表
- 学习计划表
- 沟通模板
- 正念/呼吸练习
- 校园资源导航

### 5.6 风险帮助页
作用：处理敏感与高风险场景。
包含：
- 当下可以做什么
- 联系谁
- 学校支持资源
- 紧急帮助说明

## 6. 智能助教产品定义
### 6.1 定位
它不是泛聊天机器人，也不是独立产品，而是网站中的核心互动角色。

### 6.2 职责
- 回答课程相关问题
- 提供学习建议
- 引导进入练习和情景模拟
- 推荐资源
- 在必要时给出风险帮助提示

### 6.3 不承担的职责
- 不做医疗诊断
- 不替代心理咨询师
- 不处理高危危机干预本身
- 不脱离网站内容自由发挥成泛助手

### 6.4 技术约束
- 直接调用千问 API
- 回答边界由网站产品规则与内容规则控制

## 7. 动画形象需求（V1）
### 7.1 目标
让智能助教具有陪伴感、引导感和可识别性，不只是一个聊天框。

### 7.2 基本要求
- 角色有固定形象
- 角色可动，不是静态图
- 至少有待机、说话、欢迎、提示几种状态
- 风格要亲和、可信、不过度幼态或娱乐化

### 7.3 第一版建议
优先采用轻量 2D 动画角色或 Live2D 风格方案，不一开始做重型 3D 数字人。
